# PlanGraph

Validate your implementation plan against the real codebase before you code.

## Overview

PlanGraph is a developer CLI tool that checks a contributor-authored implementation plan (`plan.md`) against a repository's code graph (generated via Graphify). It identifies mapped entities, direct and indirect impact, dependencies, related tests, and potential ambiguities without modifying the codebase.
